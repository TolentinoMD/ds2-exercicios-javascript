Página estática

Página estática é aquela cujo conteúdo já está pronto em um arquivo armazenado no servidor e é entregue ao navegador exatamente como foi gravado. O servidor apenas localiza o arquivo e o devolve, sem executar nenhum processamento ou consulta a banco de dados. Todos os visitantes recebem o mesmo resultado, e qualquer alteração exige a edição manual do arquivo por um desenvolvedor.

Exemplo real

A documentação do MDN Web Docs e sites institucionais simples publicados no GitHub Pages: são arquivos .html, .css e imagens servidos diretamente, idênticos para qualquer visitante.

Página dinâmica

Página dinâmica é aquela cujo conteúdo é gerado no momento em que a requisição chega ao servidor. Um programa (em PHP, Node.js, Python, Java, entre outros) é executado, normalmente consulta um banco de dados ou uma API, monta o HTML de acordo com quem está pedindo e só então envia a resposta. O mesmo endereço pode devolver conteúdos diferentes para usuários diferentes ou em momentos diferentes.

Exemplo real

O feed do Instagram ou a página "Meus pedidos" da Amazon: cada usuário recebe uma página montada com os dados da própria conta, buscados em banco de dados no instante do acesso.

Caminho básico de uma requisição

  1. O usuário digita o endereço na barra do navegador ou clica em um link.
  2. O navegador consulta o DNS para descobrir o endereço IP correspondente ao domínio.
  3. O navegador abre uma conexão com o servidor (TCP e, em HTTPS, o handshake TLS).
  4. O navegador envia uma requisição HTTP (por exemplo, GET /index.html) com cabeçalhos e, quando existem, dados do formulário.
  5. O servidor web recebe a requisição e identifica o recurso solicitado.
  6. Se o recurso for estático, o servidor apenas lê o arquivo em disco; se for dinâmico, ele aciona o código do lado servidor, que consulta o banco de dados e gera o HTML.
  7. O servidor devolve uma resposta HTTP com um código de status (200, 404, 500…), cabeçalhos e o corpo do documento.
  8. O navegador interpreta o HTML, monta o DOM e solicita os arquivos vinculados (CSS, JavaScript, imagens), repetindo o ciclo para cada um.
  9. O navegador aplica os estilos, executa o JavaScript e renderiza a página final na tela do usuário.
