Como executar

  1. Pressione F12 e abra a aba Console.
  2. Clique em Fazer login. São permitidas até três tentativas.
  3. Credenciais válidas: admin / 1234.
  4. Erre de propósito três vezes para ver o bloqueio.

Aviso importante

Como no Exercício 9, este login é client-side e serve apenas para praticar laços e condicionais. O bloqueio existe somente na memória da página: basta recarregar para zerar o contador. Em um sistema real, a contagem de tentativas fica no servidor, associada à conta ou ao IP, e costuma vir acompanhada de espera progressiva entre as tentativas.

Estrutura do programa

Elemento Código Papel
Repetição while (tentativa <= 3) Repete a solicitação enquanto houver tentativas disponíveis.
Condicional if (usuario === ... && senha === ...) Decide entre acesso permitido e nova tentativa.
Saída antecipada break Encerra o laço imediatamente quando o acesso é permitido.
Sinalizador let autenticado = false Guarda o motivo da saída do laço, para decidir a mensagem final.
Contador tentativa++ Avança a contagem e garante que o laço termine.

O sinalizador é necessário porque o laço pode terminar de duas formas diferentes: por acerto (break) ou por esgotamento das tentativas. Sem ele, não haveria como distinguir os dois casos após o while.
