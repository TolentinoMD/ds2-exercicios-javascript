Como executar

  1. Pressione F12 e abra a aba Console.
  2. Clique em Fazer login e informe usuário e senha.
  3. Credenciais válidas: admin / 1234.

Aviso importante

Este login existe apenas para praticar estruturas condicionais. Ele é client-side: as credenciais estão no código-fonte, visíveis para qualquer pessoa que abra o DevTools. Em um sistema real, a verificação acontece no servidor, a senha é armazenada como hash e nunca chega ao navegador. Veja o Exercício 2.

Atribuição (=) e comparações (== e ===)

Operador Nome O que faz Exemplo
= Atribuição Coloca um valor dentro de uma variável e devolve esse valor. usuario = "admin"
== Igualdade solta Compara apenas o valor, convertendo tipos antes (coerção). "1234" == 1234 → true
=== Igualdade estrita Compara valor e tipo, sem nenhuma conversão. "1234" === 1234 → false
