Regras aplicadas

Faixa Condição no código Saída
Entrada inválida vazio, texto, negativo ou cancelado Idade inválida
Menos de 16 anos idade < 16 Não pode votar
16 ou 17 anos idade < 18 Voto opcional
18 anos ou mais demais casos Voto obrigatório

A ordem das condições importa: como o else if só é avaliado quando o anterior falha, ao chegar em idade < 18 já se sabe que a idade é 16 ou mais. Não é preciso escrever idade >= 16 && idade < 18.
