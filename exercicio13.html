Como executar

  1. Pressione F12 e abra a aba Console.
  2. Recarregue a página: as funções são chamadas automaticamente com valores de exemplo.
  3. Use o painel abaixo para testar cada função com seus próprios valores.

As quatro funções

Assinatura Parâmetros Retorno Responsabilidade
somar(numero1, numero2) 2 números number Devolve a soma dos dois valores recebidos.
calcularMedia(nota1, nota2) 2 números number Devolve a média aritmética das duas notas.
classificarMedia(media) 1 número string Devolve Aprovado, Recuperação ou Reprovado.
criarSaudacao(nome) 1 texto string Devolve uma mensagem personalizada com o nome recebido.

Nenhuma delas escreve no console: cada função apenas retorna um valor. Quem chama decide o que fazer com o resultado — exibir, guardar em variável ou passar para outra função.

Composição: as funções trabalhando juntas

O retorno de calcularMedia() entra direto em classificarMedia(). É isso que torna funções reutilizáveis úteis: cada uma resolve uma parte e as saídas se encaixam.
