Comparação entre as duas formas

Aspecto Concatenação com + Template string
Sintaxe Aspas simples ou duplas, unidas por +. Crases (`) com ${variavel} no meio do texto.
Legibilidade Piora conforme cresce: alterna aspas, sinais de + e espaços soltos. O texto final fica visível de forma contínua, como será exibido.
Espaços Precisam ser digitados dentro das aspas; esquecê-los é o erro mais comum. Ficam naturalmente no texto, sem risco de omissão.
Quebra de linha Exige \n ou várias concatenações. Basta quebrar a linha dentro das crases.
Expressões Precisam ser calculadas fora ou entre parênteses. Aceita expressões diretamente: ${idade + 5}.
Disponibilidade Existe desde as primeiras versões do JavaScript. Introduzida no ES6 (2015); padrão nos navegadores atuais.
